# Block Memento

Block Memento is a browser extension that helps you remember why you blocked users on Twitter/X.

## Features

- Create notes to remember block reasons for Twitter/X profiles
- Store notes locally
- Automatically display notes on profile pages
- Works on both twitter.com and x.com domains

## Installation

1. Download this project to your computer
2. In Chrome:
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the downloaded folder

## Usage

1. Go to a user's profile page on Twitter/X
2. Click the extension icon
3. Write your note and click "Save Note"
4. The note will be automatically displayed on the profile page

## Requirements

- Chrome 88 or higher
